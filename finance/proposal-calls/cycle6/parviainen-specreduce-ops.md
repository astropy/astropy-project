### Project Description / Scope of Work

This project continues my work in the `specreduce` package project management, maintenance, and development. 

#### Project / Work / Deliverables

**Maintenance and project management**

* reviewing pull requests and triaging GitHub issues,
* preparing and publishing releases, keeping PyPI and conda-forge in sync,
* keeping `specreduce` aligned with Astropy's development guidelines, and
* coordinating and mentoring community contributions.

**Development priorities**

1. template-matching wavelength calibration, similar to PypeIt,
2. instrument-specific recipes and walkthroughs in the tutorials,
3. interoperability with Gemini data, including tests and
   benchmarks based on Gemini data,
4. improved ASDF support for, and contributing to the 2027 objective on 
   interoperability with performant I/O formats,
5. infrastructure for reducing multi-object spectrograph data,
6. other functionality requested in the issue tracker.

The minimum budget covers maintenance and priorities 1–3. Progress will be
reported in the tracking issue and visible in releases and merged PRs.
