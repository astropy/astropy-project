**Proposal Category**: Innovations

### Project Team

### Project Description / Scope of Work
This request is to fund engineering time specifically dedicated to support
maintainance across coordinated and if needed, affialiated packages.
The expected scope is the same as my operations proposal which is focused on
compatibility fixes and necessary infrastructural evolutions and improvements.

#### High Priority Objectives

This proposal incidentally provides a segue into completing the following
priority objectives:

- O3: Identify and address single points of failure throughout the infrastructure of the Astropy ecosystem
  - KR3.1: An audit is carried out, accessible to the CoCo and SPOC, listing every piece of project infrastructure and which people or roles operate each one 
- O5: Improve the sustainability and maintenance of coordinated and affiliated packages
  - KR5.2: Criteria are published for automatically determining when a package needs help with maintenance

Specifically, I propose to conduct these tasks organically at first, while I
work with other actors and actually give a hand with maintenance, and then use
my field experience as the starting point to conduct a more formal audit (KR3.1)
and contribute towards KR5.2 either partially or in full in budget allows. 

#### Project / Work / Deliverables
An example concrete deliverable is to ensure all coordinated packages follow
[the more robust implementation of `oldestdeps` backward compatibility checks I
recently developed for the core
package](https://github.com/astropy/astropy/pull/19000).

The exact scope is intentionally left undefined to account for intrisically
unpredictible on-demand tasks.
