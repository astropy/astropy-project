**Proposal Category**: Innovations

### Project Team

### Project Description / Scope of Work
The goal is to revive, publish, advance and implement an APE that's been dormant
for a year but received uniformly positive feedback at the time
https://github.com/neutrinoceros/astropy-APEs/pull/1

In short, we propose splitting out the compiled modules of `astropy` that rarely
change but are a bottleneck on the release pipeline into a new, separate
package.
