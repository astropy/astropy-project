### Project Description / Scope of Work
This project covers work in the following areas:

* Maintenance and development of new features in sub-packages in the core astropy package as well as coordinated packages for which Robitaille and Mumford are maintainers:
    * astropy.visualization
    * astropy.io.fits
    * astropy.timeseries
    * astropy-healpix
    * reproject
* Activities relating to other roles:
    * Release team (Robitaille)
    * Security team (Robitaille)
    * Documentation Infrastructure (Mumford & Robitaille)
    * Testing Infrastructure (Mumford & Robitaille)
    * Community Engagement Coordinator [Slack, Discourse, Mas] (Mumford)
    * Strategic Planning Committeee (Robitaille)
* Maintenance and development of the shared OpenAstronomy tooling and infrastructure, mainly related to continuous integration and releases
