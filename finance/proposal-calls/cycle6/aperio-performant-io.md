### Measure and improve I/O performance in astropy and develop distributed FITS format

**Proposal Category**: Innovations

### Project Team

This proposal is to fund the following people at [Aperio Software](https://aperiosoftware.com):

* Thomas Robitaille
* Stuart Mumford

This could also fund other individuals working at Aperio Software if required.

### Project Description / Scope of Work

The goal of this project is to measure and improve performance for reading and writing files in different formats with astropy, as well as to prototype a new cloud-friendly chunked FITS-based format.

#### High Priority Objectives

This work will directly address the following high-priority objective:

*Improve and maintain interoperability with performant I/O file formats and libraries*
